# Toilet Escape

Static one-file game. No build step.

## Deploy on Vercel
1. Upload this folder (or the ZIP contents) to a GitHub repo, or drag it into Vercel's "Add New > Project" import / use `vercel` CLI.
2. Framework Preset: **Other**. Build Command: empty. Output Directory: empty (root).
3. Deploy.

## AdSense later
In `index.html`, find the two comments `Ad slot (top)` and `Ad slot (bottom)` and paste your AdSense `<ins>` units inside the `<div class="ad">` blocks. Add the AdSense script tag in `<head>`.
